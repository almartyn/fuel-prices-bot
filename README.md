# Fuel Prices Bot

Telegram-бот, який раз на день публікує в Telegram-канал актуальні ціни на пальне з сайтів мереж АЗС України та показує, як вони змінилися порівняно з попереднім днем.

> Статус: **проєктування**. Документ описує цільову архітектуру; код ще не написаний.

## Як це працює коротко

1. GitHub Actions щодня за розкладом запускає скрипт на Node.js.
2. Скрипт завантажує сторінки з цінами з сайтів OKKO, WOG, UPG і SOCAR та витягує з них ціни.
3. Ціни приводяться до єдиного формату і перевіряються на адекватність.
4. Поточні ціни порівнюються з попереднім збереженим знімком (зазвичай вчорашнім).
5. Бот формує пост і надсилає його в канал через Telegram Bot API.
6. Новий знімок цін зберігається в JSON-файл і комітиться в репозиторій, щоб завтра було з чим порівнювати.

## Технології

| Що | Чим |
|---|---|
| Мова і середовище | Node.js 24 LTS або новіший, ES-модулі |
| HTTP-запити | вбудований `fetch` |
| Розбір HTML | `cheerio` |
| Сайти, що рендеряться через JavaScript | `playwright` (лише за потреби) |
| Telegram | прямі запити до Bot API через `fetch`, без бібліотек |
| Зберігання | JSON-файли в папці `data/` |
| Тести | вбудований `node:test` |
| Запуск за розкладом | GitHub Actions (`schedule`) |

## Швидкий старт (після реалізації)

```bash
git clone <repo-url> fuel-prices-bot
cd fuel-prices-bot
npm install
cp .env.example .env      # заповнити токен бота і канал
npm run dry-run           # зібрати ціни і показати пост у консолі, нічого не публікуючи
npm start                 # зібрати ціни і опублікувати в канал
```
