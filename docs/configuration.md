# Конфігурація

Уся конфігурація задається через змінні середовища. Локально — у файлі `.env` (не комітиться), у GitHub Actions — через Secrets і Variables репозиторію.

## Змінні

| Змінна | Обов'язкова | За замовчуванням | Опис |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | так | — | Токен бота від BotFather. **Секрет.** |
| `TELEGRAM_CHANNEL_ID` | так | — | `@назва_каналу` або числовий ID `-100...` |
| `TELEGRAM_ADMIN_CHAT_ID` | ні | — | Куди надсилати технічні сповіщення. Якщо не задано — помилки лише в лог. |
| `DRY_RUN` | ні | `false` | `true` — зібрати ціни і вивести пост у консоль без публікації і без збереження. |
| `OFFLINE` | ні | `false` | `true` — відповіді сайтів беруться з `test/fixtures/` замість мережі. Лише разом з `DRY_RUN=true`. |
| `FORCE` | ні | `false` | `true` — опублікувати, навіть якщо сьогодні вже публікували. |
| `SOURCES` | ні | усі | Список джерел через кому, наприклад `okko,wog`. Зручно для налагодження. |
| `PRICE_MIN` | ні | `20` | Мінімальна правдоподібна ціна за літр, грн. |
| `PRICE_MAX` | ні | `200` | Максимальна правдоподібна ціна за літр, грн. |
| `MAX_DAILY_CHANGE_PCT` | ні | `15` | Зміна за день більша за цей відсоток вважається підозрілою. |
| `HTTP_TIMEOUT_MS` | ні | `20000` | Таймаут одного HTTP-запиту. |
| `HTTP_RETRIES` | ні | `3` | Кількість спроб на джерело. |
| `LOG_LEVEL` | ні | `info` | `debug` / `info` / `warn` / `error` |
| `TZ_NAME` | ні | `Europe/Kyiv` | Часовий пояс для дат у пості й у назвах файлів. |

## `.env.example`

Цей файл комітиться в репозиторій як шаблон:

```dotenv
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHANNEL_ID=@fuel_prices_ua
TELEGRAM_ADMIN_CHAT_ID=

DRY_RUN=false
FORCE=false
# SOURCES=okko,wog

LOG_LEVEL=info
```

Для читання `.env` локально використовуємо вбудований у Node.js прапорець: `node --env-file-if-exists=.env src/index.js`. Окрема бібліотека `dotenv` не потрібна.

## Перевірка при старті

`src/config.js` при запуску:

1. Читає всі змінні й приводить типи (`"true"` → `true`, `"20"` → `20`).
2. Якщо обов'язкова змінна відсутня і це не `DRY_RUN`, або значення некоректне (не число, невідомий `LOG_LEVEL`, неіснуючий часовий пояс, невідоме джерело в `SOURCES`) — завершує роботу з кодом 1 і переліком **усіх** проблем одразу, наприклад `TELEGRAM_BOT_TOKEN is not set`.
3. Повертає глибоко заморожений об'єкт конфігурації (`Object.freeze`), який передається в інші модулі.

## GitHub Actions

| Назва | Тип | Значення |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Secret | токен бота |
| `TELEGRAM_ADMIN_CHAT_ID` | Secret | ваш особистий chat_id |
| `TELEGRAM_CHANNEL_ID` | Variable | `@fuel_prices_ua` |

Налаштовуються в репозиторії: Settings → Secrets and variables → Actions.
