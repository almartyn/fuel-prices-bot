# Налаштування Telegram

## 1. Створити бота

1. Відкрити [@BotFather](https://t.me/BotFather) у Telegram.
2. Надіслати `/newbot`.
3. Ввести ім'я бота (як його бачать користувачі), наприклад `Ціни на пальне`.
4. Ввести username, що закінчується на `bot`, наприклад `fuel_prices_ua_bot`.
5. BotFather поверне **токен** вигляду `1234567890:AAH...`. Це секрет: не комітити в репозиторій, не показувати нікому.

## 2. Створити канал

1. У Telegram: «Новий канал».
2. Для публічного каналу задати посилання, наприклад `t.me/fuel_prices_ua`. Тоді `chat_id` для бота — `@fuel_prices_ua`.
3. Для приватного каналу `chat_id` — числовий ідентифікатор вигляду `-1001234567890` (як його отримати — нижче).

## 3. Додати бота в канал

1. Налаштування каналу → «Адміністратори» → «Додати адміністратора».
2. Знайти бота за username.
3. Залишити право **«Публікація повідомлень»**, решту можна вимкнути.

## 4. Перевірити

```bash
curl -s "https://api.telegram.org/bot<TOKEN>/sendMessage" \
  -d chat_id=@fuel_prices_ua \
  -d text="Тест"
```

Відповідь з `"ok":true` означає, що все налаштовано. У каналі з'явиться повідомлення «Тест».

## Як дізнатися числовий ID приватного каналу

1. Опублікувати будь-яке повідомлення в каналі.
2. Виконати:
   ```bash
   curl -s "https://api.telegram.org/bot<TOKEN>/getUpdates"
   ```
3. У відповіді знайти `"chat":{"id":-100...}` — це і є `chat_id`.

## Чат для технічних сповіщень

Боту корисно мати окремий чат, куди він пише про помилки (сайт не відповів, ціни підозрілі тощо), щоб не засмічувати канал.

1. Написати боту в особисті будь-яке повідомлення (інакше бот не зможе писати вам першим).
2. Виконати `getUpdates` і знайти `"chat":{"id":123456789}` — це ваш особистий `chat_id`.
3. Записати його в змінну `TELEGRAM_ADMIN_CHAT_ID` (див. [Конфігурація](configuration.md)).

## Використані методи Bot API

| Метод | Навіщо |
|---|---|
| `sendMessage` | Публікація поста в канал і сповіщення адміну |
| `getMe` | Перевірка, що токен дійсний (опційно, при старті) |

Приклад виклику з коду:

```js
const res = await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    chat_id: channelId,
    text,
    parse_mode: 'HTML',
    link_preview_options: { is_disabled: true },
  }),
});
const data = await res.json();
if (!data.ok) throw new Error(`Telegram: ${data.description}`);
```
