# Формат поста

## Шаблон

```
⛽ <b>Ціни на пальне — 23 вересня 2026</b>
<i>Зміни відносно 22 вересня</i>

<b>OKKO</b>
<code>А-95   56.99 ▲0.30</code>
<code>А-95+  59.99 ▲0.30</code>
<code>ДП     54.49 ▼0.20</code>
<code>Газ    32.99 =</code>

<b>WOG</b>
<code>А-95   56.89 ▲0.20</code>
<code>ДП     54.39 ▼0.10</code>

<b>Середні ціни</b>
<code>А-95   56.85 ▲0.22</code>
<code>ДП     54.44 ▼0.15</code>

⚠️ Не вдалося отримати дані: SOCAR

Джерела: okko.ua, wog.ua, upg.ua, socar.ua
```

Як це виглядає в каналі:

> ⛽ **Ціни на пальне — 23 вересня 2026**
> *Зміни відносно 22 вересня*
>
> **OKKO**
> `А-95   56.99 ▲0.30`
> `А-95+  59.99 ▲0.30`
> `ДП     54.49 ▼0.20`
> `Газ    32.99 =`
> ...

Моноширинний шрифт (`<code>`) потрібен, щоб ціни стояли рівною колонкою.

## Правила

- **Порядок мереж** — фіксований, як у реєстрі джерел: OKKO, WOG, UPG, SOCAR.
- **Порядок пального** — фіксований: А-92, А-95, А-95+, А-100, ДП, ДП+, Газ. Види, яких у мережі немає, пропускаємо.
- **Ціна** — завжди два знаки після коми: `56.90`, не `56.9`.
- **Позначки змін:**
  - `▲0.30` — подорожчало;
  - `▼0.20` — подешевшало;
  - `=` — без змін;
  - без позначки — немає з чим порівнювати.
- **Рядок «Зміни відносно …»** показуємо, лише якщо попередній знімок існує. Якщо він не вчорашній — обов'язково вказуємо його дату.
- **Блок «Середні ціни»** — лише для видів пального, які є щонайменше у двох мережах (див. [Зберігання і порівняння](storage-and-comparison.md#середня-ціна)).
- **Блок «Не вдалося отримати дані»** — лише якщо хоч одне джерело впало.
- **Дата** — українською, за київським часом. Будується з київської дати `YYYY-MM-DD` і списку місяців у родовому відмінку (`23 вересня 2026`). `Intl.DateTimeFormat('uk-UA')` не використовуємо: він додає « р.» і залежить від версії ICU. Рік у рядку «Зміни відносно …» показуємо, лише якщо він відрізняється від поточного.
- **Вирівнювання** — назва пального доповнюється пробілами до 7 символів, ціни вирівнюються по правому краю за найдовшою ціною в пості (ціни від 100 грн мають на цифру більше).

## Технічні деталі Telegram

- Використовуємо `parse_mode: "HTML"`. Він простіший за MarkdownV2, де треба екранувати багато символів.
- Будь-який текст, отриманий з сайтів (наприклад, назви мереж), екрануємо: `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`.
- Ліміт повідомлення — 4096 символів. Пост на 4 мережі займає близько 600–800 символів, запас великий. Форматер все одно перевіряє довжину і, якщо ліміт перевищено, кидає помилку, а не обрізає текст мовчки.
- `disable_web_page_preview: true` (у новіших версіях API — `link_preview_options: { is_disabled: true }`), щоб під постом не з'являлось прев'ю посилань.
